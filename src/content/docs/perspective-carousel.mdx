### Props

| Prop             | Type                             | Default | Description                                        |
| ---------------- | -------------------------------- | ------- | -------------------------------------------------- |
| `images`         | `{ src: string; alt: string }[]` | —       | Array of image objects to display in the carousel  |
| `className`      | `string`                         | —       | Additional CSS classes for the wrapper             |
| `showPagination` | `boolean`                        | `false` | Show clickable pagination dots                     |
| `showNavigation` | `boolean`                        | `false` | Show previous/next navigation arrows               |
| `loop`           | `boolean`                        | `true`  | Enable infinite looping of slides                  |
| `autoplay`       | `boolean`                        | `false` | Enable automatic slide progression                 |
| `spaceBetween`   | `number`                         | `40`    | Space in pixels between slides                     |
| `slidesPerView`  | `number`                         | `2.43`  | Number of slides visible at once (supports decimals) |
